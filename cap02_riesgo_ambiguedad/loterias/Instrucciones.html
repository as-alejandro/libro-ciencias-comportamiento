En este experimento tomará {{ C.NUM_DECISIONES }} decisiones. En cada una elegirá entre dos opciones, A y B. Cada opción es una lotería:

  • La opción A paga {{ session.config.a_alto }} UME o {{ session.config.a_bajo }} UME.
  • La opción B paga {{ session.config.b_alto }} UME o {{ session.config.b_bajo }} UME.

En cada decisión cambiará la probabilidad de obtener cada uno de los dos resultados.

Cómo se determina su pago

Solo se pagará una de sus {{ C.NUM_DECISIONES }} decisiones. Cuando las haya tomado todas, el computador hará dos sorteos:

  1. Elegirá al azar cuál de las {{ C.NUM_DECISIONES }} decisiones se paga. Todas tienen la misma probabilidad de ser elegidas.
  2. Una vez elegida la decisión, se aplicará la opción que usted escogió en ella. Por ejemplo, si la decisión elegida es la 1 y usted escogió la opción A, puede ganar {{ session.config.a_alto }} UME con probabilidad {{ C.PASO_PROB }} % o {{ session.config.a_bajo }} UME con probabilidad {{ resto_1 }} %. El computador elegirá entonces al azar un número entre 1 y {{ C.SORTEO_MAX }}. Si el número está entre 1 y {{ C.PASO_PROB }}, ganará {{ session.config.a_alto }} UME; si está entre {{ siguiente_1 }} y {{ C.SORTEO_MAX }}, ganará {{ session.config.a_bajo }} UME.

Usted no sabe qué decisión se pagará, así que le conviene elegir en cada una la opción que realmente prefiere. No hay respuestas correctas ni incorrectas.

Sus ganancias se expresan en UME (unidades monetarias experimentales). Al final, las UME se convierten en pesos: 1 UME = {{ tasa }}. {{ if hay_pago_fijo }}Además, recibirá un pago fijo de {{ pago_fijo }} por su participación.{{ endif }}
