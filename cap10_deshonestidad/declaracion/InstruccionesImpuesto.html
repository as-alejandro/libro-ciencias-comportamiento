Declaración de ingresos

Después de conocer tu ingreso deberás decidir cuánto deseas declarar. Puedes declarar cualquier cantidad entre 0 y el total de {{ session.config.etiqueta_moneda }} que hayas obtenido. La cantidad declarada será la base para calcular los impuestos que debes pagar.

Por ejemplo, si has obtenido 100 {{ session.config.etiqueta_moneda }}, podrás declarar cualquier cantidad entre 0 y 100 {{ session.config.etiqueta_moneda }}.

Tasa impositiva

La tasa impositiva es del {{ imp.total }} %. Esto significa que por cada 100 {{ session.config.etiqueta_moneda }} que declares pagarás {{ imp.total }} {{ session.config.etiqueta_moneda }} de impuestos.

De cada {{ imp.total }} {{ session.config.etiqueta_moneda }} que pagues:

  • {{ imp.fondo }} se destinan al fondo público de tu grupo.
  • {{ imp.admin }} se destinan a cubrir gastos administrativos.
    • {{ if imp.destino == 'sin_explicacion' }}
  • {{ imp.extra }} se destinan a otros gastos.
    • {{ elif imp.destino == 'inversion' }}
  • {{ imp.extra }} se destinan a inversiones de largo plazo en infraestructura que beneficiarán a otras personas en el futuro.
    • {{ elif imp.destino == 'salarios' }}
  • {{ imp.extra }} se destinan a pagar mayores salarios a servidores públicos.
    • {{ endif }}
{{ if imp.destino == 'inversion' }}

Estas inversiones no modifican el pago que tú ni los demás miembros de tu grupo reciben durante esta sesión.

{{ elif imp.destino == 'salarios' }}

Estos gastos adicionales no modifican el fondo público ni los pagos que reciben los participantes durante esta sesión.

{{ endif }}

Por ejemplo:

  • Si recibes 100 y declaras 100, pagas {{ ej100.total }} de impuestos: {{ ej100.fondo }} al fondo público, {{ ej100.admin }} a gastos administrativos{{ if imp.extra }} y {{ ej100.extra }} a {{ if imp.destino == 'sin_explicacion' }}otros gastos{{ elif imp.destino == 'inversion' }}inversiones de largo plazo{{ else }}salarios de servidores públicos{{ endif }}{{ endif }}.
  • Si recibes 100 y declaras 60, pagas {{ ej60.total }} de impuestos: {{ ej60.fondo }} al fondo público, {{ ej60.admin }} a gastos administrativos{{ if imp.extra }} y {{ ej60.extra }} a {{ if imp.destino == 'sin_explicacion' }}otros gastos{{ elif imp.destino == 'inversion' }}inversiones de largo plazo{{ else }}salarios de servidores públicos{{ endif }}{{ endif }}.

Impuesto total = ingreso declarado × {{ imp.total }} %
