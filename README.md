# libro-ciencias-comportamiento
Programación en oTree de los experimentos del libro de ciencias del comportamiento, organizados por capítulo. Incluye experimentos originales y adaptaciones traducidas al español, disponibles para su consulta, uso y replicación en docencia e investigación.

# Experimentos de ciencias del comportamiento en oTree

Este repositorio contiene la programación de los experimentos que acompañan al libro
*[Título del libro]*, en el área de ciencias del comportamiento. Los experimentos están
organizados por capítulo y desarrollados en [oTree](https://www.otree.org/).

Incluye tanto experimentos programados específicamente para el libro como adaptaciones
al español de experimentos con programación previa.

## Estructura

Cada capítulo tiene su propia carpeta dentro de `capitulos/`, y cada experimento su
subcarpeta con el código oTree y un README que describe el objetivo, el diseño y las
instrucciones de ejecución.

## Requisitos

- Python 3.9 o superior
- oTree 5 (`pip install otree`)

## Ejecución local

    pip install -r requirements.txt
    otree devserver

Abre http://localhost:8000 en el navegador.
